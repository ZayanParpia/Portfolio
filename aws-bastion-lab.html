Project Overview

I built a bastion host on AWS using an EC2 instance in a public subnet. Remote access to the bastion host is through AWS Systems Manager (SSM), and from there I can SSH into a private EC2 instance inside a private subnet.

This project taught me about SSM, network ACLs (NACLs), access control lists (ACLs), and subnetting. It also showed me how to restrict access to private instances without exposing them directly to the internet.
