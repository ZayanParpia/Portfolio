Wazuh Rule 5557 — Failed Authentication Alert

Wazuh parses the auth log and fires rule 5557 (Level 5) per failed sudo. Custom rule 100002 aggregates 3 failures within 5 minutes into a high-severity brute-force alert.

Wazuh Rule 5403 — Successful Sudo Session (Phase 2)

Alert triggered when valid credentials are used for elevation. Wazuh logs the session, command, and user context.

FIM detects an edit to /etc/sudoers, generating an immediate alert with file hash and modification timestamp.

Simulation Outline

"This simulation validates Wazuh's capability to detect Linux privilege escalation, persistence mechanisms, and suspicious administrative behaviour. Sudo credentials are brute-forced to generate failed log spikes, successful sudo elevations are audited, critical configuration files (/etc/sudoers) are modified to test FIM alerts, and user group escalations are monitored via Auditd syscall tracking. All activities are mapped to MITRE ATT&CK tactics."

What I Learned

This simulation bridged blue-team monitoring with active adversarial testing. Key skills developed:

Technical Skills
  • Custom Wazuh Rules: Used frequency, timeframe, and parent SID matching to build a brute-force correlation rule.
  • Auditd Syscall Tracking: Configured watch rules for group membership changes and mapped them back to SIEM decoders.
  • File Integrity Monitoring: Configured ossec.conf to scan /etc/sudoers for unauthorised changes.
  • Linux OS Internals: Deepened understanding of SUID bits, group management, and sudo credential pathways.
Security Concepts
  • MITRE ATT&CK Mapping: Aligned each phase to Privilege Escalation, Persistence, and Defense Evasion tactics.
  • Alert Tuning: Discovered how legitimate sudo group additions can generate false positives requiring careful baseline configuration.
Professional Takeaways
  • SIEM Documentation: Learned to navigate Wazuh's XML rule schema to configure detection criteria.
  • Evidence-Based Validation: Produced verified logs, alerts, and dual-video recordings for reporting and audit traceability.
