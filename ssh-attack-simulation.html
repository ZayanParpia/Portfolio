Simulation Report

This simulation shows a ssh brute force attack where an attacker (Kali Linux vm with hydra) to brute force port 22 on the victim IP (Ubuntu endpoint).

Detection Rules

The same source IP must generate 3 or more failed SSH authentication attempts within 60 seconds, followed by a successful login and a change to the SSH authorized_keys file. This sequence triggers an automated response that terminates the source session, changes the password, and clears the authorized keys file.

Mean time to detect (MTTD): a few seconds.
